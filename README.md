# 🎮 Hangman Game

A simple **Hangman Game** built using Python. The player has to guess the hidden word one letter at a time before running out of attempts.

## ✨ Features

* Randomly selects a word from a list
* Allows the player to guess letters
* Shows correctly guessed letters
* Displays remaining attempts
* Prevents repeated guesses
* Shows the word when the game is over
* Displays a win message when the word is guessed correctly

## 🛠️ Concepts Learned

* Python variables
* Lists
* `random` module
* `random.choice()`
* `while` loops
* `for` loops
* `if-elif-else` conditions
* String operations
* User input
* Basic game logic

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or terminal.
4. Run:

```bash
python hangman.py
```

## 🎯 How to Play

1. The game randomly selects a hidden word.
2. Guess one letter at a time.
3. Correct guesses reveal the letters.
4. Wrong guesses reduce your attempts.
5. Guess the complete word before your attempts reach zero.
